# Signal Dictionary

This project uses a normalized `signal_dictionary` table in SQLite. Below are the canonical signals generated by the simulator and stored in the database.

| signal_name | unit | description | valid_minimum | valid_maximum | source | data_maturity |
|---|---|---|---|---|---|---|
| vehicle_speed | km/h | Instantaneous vehicle speed from simulated CAN | 0 | 200 | sim.can | simulated |
| soc | % | State of charge of the battery | 2 | 100 | sim.can | simulated |
| range_estimate | km | Estimated remaining driving range | 0 | 500 | sim.can | simulated |
| energy_rate | kW | Instantaneous energy consumption rate | 0 | 200 | sim.can | simulated |
| consumption_running | Wh/km | Energy consumption while driving | 50 | 300 | sim.can | simulated |
| battery_temp | C | Battery pack temperature | -40 | 80 | sim.can | simulated |
| motor_temp | C | Electric motor temperature | -20 | 120 | sim.can | simulated |
| ambient_temp | C | Ambient temperature around vehicle | -30 | 50 | sim.can | simulated |
| tyre_pressure_fl | bar | Front-left tyre pressure | 1.8 | 3.5 | sim.can | simulated |
| tyre_pressure_fr | bar | Front-right tyre pressure | 1.8 | 3.5 | sim.can | simulated |
| tyre_pressure_rl | bar | Rear-left tyre pressure | 1.8 | 3.5 | sim.can | simulated |
| tyre_pressure_rr | bar | Rear-right tyre pressure | 1.8 | 3.5 | sim.can | simulated |
| dc_bus_voltage | V | High-voltage bus voltage | 300 | 450 | sim.can | simulated |
| aux_battery_voltage | V | 12V auxiliary battery voltage | 11.5 | 14.8 | sim.can | simulated |
| motor_rpm | rpm | Electric motor revolutions per minute | 0 | 15000 | sim.can | simulated |
| cabin_temp | C | Passenger cabin temperature | 10 | 40 | sim.can | simulated |
| hvac_power | kW | HVAC system power draw | 0 | 5 | sim.can | simulated |
| regen_energy | kWh | Recovered energy during braking | 0 | 20 | sim.can | simulated |
| odo_vehicle | km | odometer reading | 0 | 100000 | sim.can | simulated |
| inverter_temp | C | Power inverter temperature | -20 | 100 | sim.can | simulated |
| charging_power | kW | Charging power when plugged in | 0 | 150 | sim.obc | simulated |

## Event Types

| event_type | severity | description |
|---|---|---|
| battery_overtemp_warning | critical | Battery temperature above warning threshold |
| thermal_derating | warning | Power derate active after thermal warning |
| adas_disengagement | warning | ADAS lateral/longitudinal control handed back to driver |
| diagnostic_trouble_code | warning/stored/ info | UDS-reported DTC (e.g., P0562, U0126) |
| energy_consumption_spike | warning | Consumption sharply above rolling baseline |
| stale_sensor_data | warning | No new samples for >10 minutes |
| trip_start | info | Trip begin event |
| trip_end | info | Trip end event |

## Trip Attributes

| attribute | type | description |
|---|---|---|
| trip_id | integer | Unique trip identifier |
| start_time | text (ISO) | Trip start timestamp |
| end_time | text (ISO) | Trip end timestamp |
| distance | real | Distance travelled in km |
| road_type | text | "city" or "highway" |
| energy_used | real | Energy used in kWh |
| scenario_id | text | Which scenario produced this trip (A–F) |
