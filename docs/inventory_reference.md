# Workspace inventory reference

The initial asset inventory for this project lives at `../work/inventory.md`
(project root `H:\tata\work\inventory.md`). It records, for every file in the
workspace: name, type, purpose, current status (ORIGINAL / NEW), what happens to
it in `final_submission/`, and any detected issues.

Key safety rules applied:
- Official case-study PDFs and the official template are never modified.
- Earlier deliverables (proposal, one-slide, Round 2 draft) are preserved;
  revised versions are written only into `final_submission/`.
- New implementation code lives only in `vehiclegpt-edge/`.
