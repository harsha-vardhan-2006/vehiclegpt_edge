# VehicleGPT Edge - Case Study 5 (Round 2)

This is the working prototype repository for VehicleGPT Edge, a local
vehicle-information assistant backed by synthetic vehicle data, SQLite
history, deterministic query routing, and an optional offline SLM/LLM path.

## What this repo is

- A Python prototype for on-device natural-language vehicle queries.
- All vehicle data here is synthetic and clearly labelled as simulated.
- The default query path is deterministic: natural-language questions are
  routed to parameterized SQL and validated against evidence, not handed to
  an LLM for numerics.
- Security boundaries are enforced in code and tests: no shell execution,
  no actuator/CAN write path, no cloud calls in the query path.

## Quick start

Requirements:
- Python 3.13
- Dependencies in `requirements.txt`

Set up and run:

```bash
cd vehiclegpt-edge
python -m pip install -r requirements.txt
python -m pytest -q
```

To launch the local web UI:

```bash
py -m uvicorn api.main:app --host 127.0.0.1 --port 8000
```

Then open `http://127.0.0.1:8000`.

To run the full demo pipeline and regenerate the benchmark results:

```bash
py -m benchmarks.benchmark --reps 20
```

If you are on Windows and `py` resolves to the correct Python, `py` is the
simpler command. If it does not, use `python` from the install path directly.

## What you get

- 60 days of synthetic vehicle data with scenarios A-F and fixed random seed.
- SQLite storage: `data/database/vehiclegpt.db`.
- 5 official case-study questions answered deterministically.
- Evidence-backed answers with validation.
- 70 automated tests across ingestion, storage, queries, analytics,
  validation, security, and API.
- Browser UI under `ui/`.

## Data and database

The database is generated by the simulator and is git-ignored by default.

If the database is missing, regenerate it:

```bash
py - <<'PY'
from storage.database import connect, init_db, load_settings
from simulator.generate_vehicle_data import generate
p = "data/database/vehiclegpt.db"
import os
os.makedirs(os.path.dirname(p), exist_ok=True)
conn = connect(p)
init_db(conn)
s = load_settings()
generate(s, conn)
conn.execute("ANALYZE")
conn.commit()
conn.close()
print("created", p, os.path.getsize(p))
PY
```

## Safety and offline operation

- The API binds to `127.0.0.1` by default.
- The query path uses parameterized SQL only.
- No external API calls are required for normal queries.
- The optional local model is off by default and is never used for numerics.

were measured on an x86 development PC, not on automotive/ARM hardware.
