- Intent classification: 8 query categories (exact lookup, event history, time-range search, trend analysis, comparison, temporal reconstruction, anomaly explanation, missing-data investigation)
- 5 official case-study questions answered deterministically
- Evidence package with validation (numerical claims -> evidence, units, timestamps, missing data disclosure)
- Answer validator: real program with automated tests (9 test cases)
- Benchmark: latency percentiles, memory measurement, environment recording
- Security: no shell/eval, no network calls in query path, no actuator-write path

- Beginner setup instructions: README.md (Windows first, then Linux) - FILE EXISTS AT REPO ROOT

NOTES:
- All data is synthetic and clearly labelled as such
- Optional local LLM (Qwen2.5 0.5B GGUF) for natural-language explanation only
- Deterministic mode works without any model download
- All queries use parameterized SQL; no raw NL in executable SQL
- No cloud dependency for normal queries
- Safety boundary explicitly enforced in architecture, not just LLM prompts
